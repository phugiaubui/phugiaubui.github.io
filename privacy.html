Agent Fleet Privacy Policy

Last updated: 27 October 2026

Agent Fleet is a personal tool. It is used only by its owner, with the owner's own Google account, and is not offered to anyone else.

What data it accesses

With the owner's permission, Agent Fleet reads and edits Google Docs and Google Drive files, including their comments, so that it can create drafts and revise them in response to the owner's comments.

How the data is used and stored

  • Data is processed only on the owner's own computer, to carry out the owner's requests.
  • The access token is stored only on that computer.
  • No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
